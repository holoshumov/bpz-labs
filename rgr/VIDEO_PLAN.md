# РГР — план відео (10–15 хв)

Запис екрана: QuickTime → «Новий запис екрана» (або Cmd+Shift+5). Термінали поруч, шрифт крупний.

| Час | Що показувати | Що говорити |
|---|---|---|
| 0:00–0:45 | Титул (README у GitHub) | «Голошумов Владислав, ІМ-31. РГР з БПЗ: імітація TLS-рукостискання, базовий варіант. Node.js, лише вбудовані `crypto` і `net`.» |
| 0:45–2:30 | Структура `rgr/`, `src/protocol.js`, `src/handshake.js` | Модулі: протокол і кадрування, транспорт за інтерфейсом, крипто, стан-машина рукостискання, захищений канал. Ролі — параметр ноди, тому розширений варіант ляже без переписування. |
| 2:30–5:30 | Два термінали: `node server.js --no-cert`, `node client.js` | Пройтися по КРОКАХ 1–7: два random по 32 Б; сервер генерує RSA-2048 і надсилає public key; крок 3 пропущено; premaster 48 Б, RSA-OAEP → 256 Б; HKDF: master і окремі ключі/IV; finished — HMAC від transcript, зашифрований GCM; показати, що `master` і ключі однакові в обох вікнах. |
| 5:30–7:00 | Чат і `/send samples/message.txt`, `cat received/*` | Кожне повідомлення — AES-256-GCM, nonce = IV ⊕ seq, AAD = тип\|seq. Файл: SHA-256 збігається на обох сторонах. Сервер може писати всім клієнтам. |
| 7:00–7:45 | (бонус) `npm run cert`, сервер із сертифікатом | Клієнт виводить subject і відбиток, перевіряє, що ключ сертифіката = ключ сервера. Повна перевірка в CA — розширений варіант. |
| 7:45–11:00 | Три термінали: сервер, `mitm.js`, клієнт на 9443 — режими keyswap, tamper, replay; потім `--bad-finished` | Keyswap: MITM розшифрував premaster, але finished не зійшовся — transcript різний. Чесно: повний MITM з двома рукостисканнями пройшов би — для цього крок 3 (CA). Tamper: 1 байт → GCM-тег не сходиться. Replay: seq=1 вдруге → відхилено. Bad finished: рукостискання не завершилось. |
| 11:00–12:00 | `npm test` | 13 тестів: рукостискання, однакові ключі, канал, файл, усі негативні сценарії, downgrade. |
| 12:00–13:30 | NOTES.md (коротко) | TLS 1.2 vs 1.3, forward secrecy: у нас RSA key exchange — без неї; у TLS 1.3 лише ECDHE. Чому окремі ключі напрямків, чому не можна повторювати nonce. |
| 13:30–14:00 | GitHub-посилання | «Код і логи — github.com/holoshumov/bpz-labs, папка rgr. Дякую.» |

Перед записом: `npm run cert` (щоб був сертифікат), `rm -rf received`, закрити зайві вікна, вимкнути сповіщення.
